# Capabilities

Each row is a core capability and each column a surface; a cell names the route, function, method or command that performs it. The [HTTP API](http.md) reference describes every route named here. The Python client writes only to a database it runs itself, made by `create` or `open`. The CLI declares and inserts only by building a new bundle.

| Capability | HTTP | TypeScript client | Python client | CLI |
|---|---|---|---|---|
| Declare views, view groups, attributes and vocabularies | `PUT /control/views/{name}`, `PUT /control/view_groups/{name}`, `PUT /control/views/{group}/{key}`, `PUT /control/attributes`, `PUT /control/vocabularies/{name}`, `PATCH /control/vocabularies/{name}/values`, `DELETE /control/views/{group}/{key}` | Not built yet | `Database.declare_view`, `declare_view_group`, `declare_attribute`, `declare_vocabulary`, `declare_columns`, `declare`, sent by `Database.commit`; `Database.drop_view` | The declaration file, checked by `tessera check` and built by `tessera build`; `tessera check --payloads` prints the matching control-plane bodies |
| Insert | `POST /control/ingest` (new items), `POST /control/values` (values on existing items) | Not built yet | `Database.insert`, sent by `Database.commit` | `tessera build` reads the declaration's sources into a new bundle. Into a running service: not built yet |
| Delete | `POST /control/changes` with `op: "delete"` | Not built yet | `Database.remove` | Not built yet |
| Suppress and lift a suppression | `POST /control/changes` with `op: "suppress"` or `op: "unsuppress"` | Not built yet | `Database.suppress`, `Database.unsuppress` | Not built yet |
| Query the map | `POST /v1/viewport` | `TesseraClient.viewport`; `Store.setView` | `Selection.sample`, `Selection.count`, `Selection.map`, `Viewer.map`, `Database.view`, `Database.map`, `Map` | Not built yet |
| Query items | `POST /v1/items` (pages of records), `POST /v1/items/{tessera_id}` (one record) | `TesseraClient.item`; `Store.pick`, `Store.describe`. Pages of records: not built yet | `Viewer.items`, `Viewer.item`, `Database.item` | Not built yet |
| Filter | `filters` in the bodies of `POST /v1/viewport`, `POST /v1/items` and `POST /v1/artifacts/browse` | `filters` on `TesseraClient.viewport` and `TesseraClient.browse`; `Store.setFilters`, `Store.setMembers`, `Store.select`; `filters` on `Store.browse` | `Selection.filter`, `Selection.within`; `filters` on `Viewer.items` and `Viewer.browse_artifacts` | Not built yet |
| Highlight | `highlight` in the body of `POST /v1/viewport` | `highlight` on `TesseraClient.viewport`; `Store.setFilters` with a clause whose verb is `highlight` | `highlight` on `Selection.sample` | Not built yet |
| Search text, and suggest category values | A `match` leaf in `filters`; `GET /v1/categories/{column}/suggest` | A `text` clause in `Store.setFilters`; `TesseraClient.suggest`, `Store.suggest` | A `match` leaf in `Selection.filter`; `Viewer.categories` and `Database.categories` with `prefix` | Not built yet |
| Declare and publish annotation layers | `PUT /control/layers`, `PUT /control/layers/{name}/artifacts`, `PATCH /control/layers/{name}/artifacts`, `DELETE /control/layers/{name}` | Not built yet | `Database.declare_layer`, `Database.declare_labels`, `Database.insert` into the layer, sent by `Database.commit`; `Database.drop_layer` | `[[layer]]` in the declaration, built by `tessera build` |
| Read annotation layers | `layers` in the body of `POST /v1/viewport`; `POST /v1/artifacts/browse`; `POST /v1/artifacts/{tessera_id}` | `layers` on `TesseraClient.viewport`, `Store.setLayers`; `TesseraClient.browse`, `Store.browse`; `TesseraClient.artifact`, `Store.openArtifact` | `layers` on `Selection.sample`; `Viewer.browse_artifacts`; `Viewer.artifact` | Not built yet |
