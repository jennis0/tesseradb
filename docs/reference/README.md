# Reference

*Skeleton.* Pages in this set and what each will hold.

- **bundle-format.md**: every file in a bundle, its layout and version. From `design/contracts.md` §2.
- **wire-format.md**: the framed Arrow stream, ordering, trailer and truncation. From `design/contracts.md` §5 and `design/streamed-serving.md`.
- [openapi/tessera.yaml](../openapi/tessera.yaml): the HTTP API, kept true by a test.
- **plugin-abi.md**: from `design/contracts.md` §4.
- **measured-facts.md**: the figures the design depends on, each with its value, the conditions, the probe directory and the date. Twenty-one figures and three negative results as of 2026-09-02; everything else in `evidence/` and `probes/` is supporting record.
- **considered-not-built.md**: the deferred sketches (`design/deferred-*.md`), `design/core-access-expressions.md`, and the unbuilt suites (`design/performance-suite.md`, `design/measurement.md`), reduced to what they proposed and why they wait.
