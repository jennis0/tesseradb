# Developing Tessera

*Skeleton.* Pages in this set and what each will hold.

- **building.md**: prerequisites (Rust stable, Node 20 or later, Python 3.12), `cargo build --release`, the client build, the Python wheel, the seventeen crates and what each is for.
- **testing.md**: the workspace tests, the conformance suite and its Python oracle, the checker scripts, the gate to run before finishing, the ignored tests and why.
- **ci.md**: the four jobs in `.github/workflows/ci.yml` and what is left out of the gate, and why.
- **releasing.md**: nothing yet. Licence, versioning, packaging and publishing are undecided.
- **how-we-work.md**: one page replacing `agents/`: fix it now; one adversarial review when a design becomes binding; rulings written as decision files; mark unbuilt machinery at the claim; the register.
- [roadmap.md](../roadmap.md): what constrains the order of work.
