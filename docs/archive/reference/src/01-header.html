Tessera: the four processes

Single-page walkthroughs of ingest, authorisation, query and update — naming the actual structures, the order they are touched, and the optimisations that are load-bearing rather than incidental. This is the companion to the white paper: that document argues why the system is built this way, this one records what is built.

Status. The architecture is specified in full and Phase 0 is measured; Phase 1 is in progress. Where a step here is a design decision that no code yet implements, it is written in the present tense like the rest — this page describes the specification, not a running system. Every structure named traces to the design corpus, and section references point at the governing document.
