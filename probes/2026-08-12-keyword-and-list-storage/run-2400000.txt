Layouts: FLAT = the utf8 column as shipped (search = text scan).
DICT+C = front-coded sorted dictionary + one u32 ordinal per present entity
         (record = ordinal lookup; eq/prefix = dictionary lookup -> ordinal-range test in a
         fixed-width scan; contains = a scan over the dictionary's own bytes).
IX+REC = dictionary + hybrid postings + 256KiB-zstd record (search never touches the record).
CSR    = offsets + one u32 code per (entity,value) above the dictionary.
CSR+IX = the same with hybrid postings derived on top (the accelerator layout).
Presence bytes (Roaring, per entity over all n) are reported separately: every layout pays
them identically where the column is partial.
